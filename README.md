## Что это

BPN Vision принимает картинку с PS5 Remote Play, Xbox, облачного Xbox, ПК (Moonlight/Sunshine), карты захвата или из видеофайла и в реальном времени улучшает её на видеокарте: суперразрешение (RTX Video, DLSS, FSR, XeSS), очистка картинки, HDR и генерация промежуточных кадров.

Честно о «4K 120 FPS»: Remote Play и облако передают до 1080p, остальное дорисовывает апскейлер. Дополнительные кадры тоже дорисованные, и с ними растёт задержка управления. Настоящий 4K-источник даёт только карта захвата.

## Чем отличается от Veyra

- **Облачный Xbox (xCloud).** Игры Game Pass Ultimate и бесплатные облачные игры (например, Fortnite) запускаются без своей консоли: «Стриминг Xbox» → «Облако».
- **Русский язык интерфейса:** Настройки → Язык интерфейса → «Русский», на русской Windows включается сам.
- **Игры на языке интерфейса:** облачные и консольные игры запрашиваются на языке программы.

## Облачный Xbox

1. На главной откройте **Стриминг Xbox** и нажмите «Войти»: программа покажет код для microsoft.com/link.
2. Переключите **Источник → Облако**.
3. Облачные игры Microsoft продаёт не во всех странах. Если программа пишет, что облако недоступно, подключите [BPN VPN](https://t.me/tgbpn_bot?start=utm_bpnvision), выберите страну с облачным Xbox (например, Германию или США) и нажмите «Обновить».
4. Выберите игру и нажмите «Играть». В часы пик бывает очередь, программа показывает примерное время ожидания.

Без подписки доступны бесплатные облачные игры. Для остальных нужна Game Pass Ultimate.
